# Parlo product, learning and engineering review

21 November 2026 · Fresh review and implementation of the supplied conversational-language-partner project.

## A. Executive product verdict

Build for the learner who recognizes a phrase on sight and goes blank when it is their turn to speak. Parlo's best starting audience is an A2–B1 learner rehearsing an everyday exchange. A French learner can now accept an invitation, find out what *ferait* contributes, practise the answer with the French hidden, save it and recall it from its English meaning the next time it is due. Voice remains the main action. The same first practice is available to someone on a phone with no microphone permission or API key.

The strongest assets are the conversational Studio, eight recognizable language identities and an existing route from expressions to review. The biggest gaps are verified feedback quality, an account-backed end-to-end test and evidence that learners can produce a useful response a week later. My product decision is to validate that last outcome before expanding the catalogue, building additional rooms or selling a usage allowance.

## D. Learning science and cultural accuracy

The authored cards now explain the grammatical or pragmatic feature that actually helps. In Spanish, *a ver si te entiendo bien* checks the speaker's own understanding. French *ferait* marks a conditional response to a proposed activity. Japanese *〜てもいいですか* asks permission. German *Könnten Sie …?* combines a softened request with formal address. Italian *potresti* softens a request made with *tu*. Mandarin *试试* reduplicates the verb. Korean *-군요* expresses a new realization. The Portuguese note distinguishes *estou praticando* from *estou a praticar* and scopes the regional claim. Each note is optional. [All 24 expressions](src/data/dailyPhrases.ts)

The Studio supports listening through playback, speaking through Live and a first retrieval attempt through a written or spoken self-check. Saved cards can also start with the English meaning for another spoken or typed retrieval attempt. The short deck is useful for rehearsal. Three expressions per language do not cover structured grammar progression. A typed phrase can be evaluated as text. A transcript can omit an audible distinction or introduce an error. Neither establishes acoustic accuracy. [CEFR, retrieval and spacing research](RESEARCH.md#learning-language-and-immersion)

For a linguistic release check, give two speakers familiar with each target variety the prompt, audience, possible meanings and current note. Have them independently mark acceptable variants, incorrect meanings, overbroad region claims and misleading cues. Resolve disagreements with a named reference or narrow the wording. Include ambiguity, mixed-register requests and examples where grammar fully explains the answer. Ship reviewed material first. Record assisted answers separately from first unaided attempts. No independent speaker panel or learner outcome study was run for this delivery.

## G. Engineering, reliability and economics

The React client sends learner actions to Express. Gemini credentials are read server-side. Firebase ID verification establishes the signed-in identity before account routes reach Drizzle/PostgreSQL. The runtime stores session transcripts as part of learning history. Scope consent and retention decisions accordingly. The review used guest browser data, in-memory fixtures and a loopback server. No account sign-in, database migration, paid request or public deployment occurred. [Server](server.ts) · [Auth middleware](src/middleware/auth.ts) · [Database schema](src/db/schema.ts)

The application caps a voice session at 15 minutes with a three-minute idle timeout and two simultaneous connections per client key. It permits 12 guest or 30 signed-in voice starts per ten minutes, 30/90 coach requests per minute and 20/60 chat requests per minute. HTTP and WebSocket guest limits now use the immediate connection address by default. Deployments with a known reverse proxy can name its trusted addresses. The limits are per server process. A shared public network can group multiple guests under one address. Hosted concurrency, provider quota, and remaining account credit must be measured separately. [Limit implementation](src/middleware/rateLimit.ts) · [Google project rate limits](https://ai.google.dev/gemini-api/docs/rate-limits)

A useful cost estimate takes actual model-specific input and output usage for audio and text, multiplies each by the price per million tokens and adds hosting and storage. Divide the total by sessions with at least one completed learner turn. For illustration only, if a measured session cost $0.03, 10 such sessions a week would cost $0.30 per learner before overhead. With a $0 discretionary budget, the authored deck, public guide and device review incur zero model calls. The example uses a hypothetical session price. Actual Parlo costs remain unmeasured. The configured model IDs and actual allowance must be confirmed in the project's AI Studio account before publishing capacity or pricing. [Google model pricing](https://ai.google.dev/gemini-api/docs/pricing) · [Configured models](server.ts)

The original production build reported 252.88 kB gzip for its initial JavaScript. The improved build reports 185.14 kB for the main module plus 53.00 kB for its preloaded dependency, 238.14 kB total, a 5.8% reduction. Scenarios, Pricing and Phrasebook now load on demand. The global backdrop uses CSS. The separate 3D bundle is 178.92 kB gzip. Four scenario images are about 0.78–0.93 MB each as files. A 500 kB uncompressed chunk warning remains. Set a performance gate on physical devices before contracting more artwork or increasing scene density. [Vite configuration](vite.config.ts) · [View loading](src/App.tsx) · [Web Vitals guidance](https://web.dev/articles/vitals)

Account data is a release gate. The SQL schema uses globally unique client IDs and owner-constrained updates. Importing the same guest record into two accounts can therefore yield a conflict without creating the second copy. Verify with two disposable accounts before promising that workflow. The local phrase edit queue covers ordinary save, delete, retry and connectivity changes. Cross-device conflict semantics for all record types and flashcard schedules still need a defined policy. The deployment's Firebase configuration, PostgreSQL backup/restore, service account and deletion behavior also require an authorized integration environment. ## H. Discovery, acquisition and retention

The public French article answers one real question, gives a natural invitation and leads into the exact saved expression. Its HTML, page title, description, internal links and self-canonical are available before JavaScript runs. Static builds and the Express server use the configured origin for the sitemap. With no public origin the app does not advertise a sitemap. Publishing the two URLs is a deployment step. The English article contains French examples, so it identifies English as the page language. Introduce alternate-language links only when equivalent pages exist. The app shell exposes product metadata. Learner transcripts and account views do not belong in a public content feed. [Guide](public/learn/french/ca-me-ferait-plaisir.html) · [Discovery sources 41–47](RESEARCH.md#discoverability)

Start with invitation replies, clarifying a misunderstanding and choosing a polite request. Each intent needs an original exchange, scope and register, an acceptable variant and a practice cue. Pilot one reviewed page at a time. Track relevant Search Console queries, then the share of landing visits that complete recall. A teacher or learner community could share a specific expression when it directly answers a question. Attribute the explanation and link to the exercise. Test optional sharing of the public page without including a personal transcript. No pages were published, communities contacted or search positions measured.

**Proposed primary measure:** weekly learners who give an appropriate unaided response in a new context using an expression they studied 2–7 days earlier. Report both count and rate. The rate denominator is all learners eligible for that follow-up, including those who never return. Publish the separate response rate to reveal attrition. A blinded human rubric initially accepts equivalent expressions and register. The current app does not instrument or establish this outcome.

| Proposed measure | Numerator / denominator and window | Source and limitation |
|---|---|---|
| Guide activation | First-time guide entrants who submit or say an answer and explicitly reveal it / eligible first-time guide entrants, same visit | Opt-in anonymous events. A silent spoken attempt is self-declared. |
| Meaningful speaking | Voice attempts reaching at least two completed learner turns and one partner reply / voice starts, same session | Local lifecycle counters. Also report microphone denial and provider failure separately. |
| Helpful explanation | Positive ratings / submitted ratings that day, plus responses / openings | One optional question to reduce interruption. Self-selection limits inference. |
| D1, D7, D30 return | Activated learners who complete a new recall attempt or two learner turns on day 1, 7 or 30 / cohort with a fully elapsed window | Count first activation once, define days in learner-local time. Exclude staff fixtures. |
| Successful transfer | Appropriate first answers / all invited, and / responses received, 2–7 days after study | Human rubric, recorded assistance and prompt IDs. Changing the prompt can change difficulty. |
| Failure, weekly reach and cost | Unusable sessions / starts daily, distinct learners completing a meaningful task weekly, attributable model spend / weekly meaningful learners | Separate device and provider reasons. Idle time and raw minutes are weak proxies for learning. |

For a consenting pilot, retain a rotating participant ID, local day, target language, cue ID, event type, assistance flag and outcome. Store provider usage totals separately. Default to aggregate reporting, give participants a deletion route, and set a short pilot retention period before recruitment. No new analytics collection was added in this release.

## I. Adversarial council verdict

These are twelve review perspectives from one author. They are hypotheses to test. No independent specialist or native-speaker panel participated.

| Perspective | Strongest objection and competing explanation | Disconfirming test and decision |
|---|---|---|
| Product strategy | Saving a phrase may feel productive even when the learner never reuses it. A searchable chat history might do as well. | Compare first appropriate unaided use at day seven. Give saved expressions priority only if this improves. |
| Learning science | A card shown immediately before recall primes short-term memory. Engagement can increase while week-later performance stays flat. | Counterbalance expressions and hold practice time constant. Require delayed transfer for a learning claim. |
| Applied linguistics | A single model answer can penalize valid variants. A literal match would make analytics look more precise than they are. | Two blinded raters score variants. Rewrite cues that produce unresolved disagreements. |
| Intercultural communication | A city motif can prime broad claims about speakers. A grammatical explanation may already answer the question. | Include prompts with no regional distinction and bilingual review. Remove unsupported cultural statements. |
| UI/UX | Voice-first can pressure shy learners. Their obstacle may be microphone permissions or a public setting. | Observe mixed first-time users performing the same task with voice and text entry. Keep a visible, quiet entry. |
| Accessibility | A successful mouse click can hide a clipped panel or a focus problem. | Reproduce with viewport bounds, keyboard and a screen reader. Block release if saving or returning cannot be completed. |
| Frontend / Three.js | A smooth desktop canvas says little about battery and sustained frame time on phones. | Compare a 10-minute room with its equivalent list. Prefer the list on devices where it performs better. |
| Backend / infrastructure | Local tests cannot establish user isolation or cost controls across deployed replicas. | A disposable two-account integration exercise and a deployment-topology check precede any account-sync or concurrency promise. |
| Growth | People can open explanations repeatedly because they are confusing. High opens may indicate failure. | Pair the opens with task success, helpfulness responses and retention denominators. Remove copy that raises opens and lowers completion. |
| Search | An indexed guide may send unqualified traffic. More pages can amplify that problem. | Use actual query relevance and completed practice per entrant. Expand only the intents that convert to practice. |
| Finance | Higher voice engagement can exhaust a beta budget sooner. Cache hit rates apply to repeated contextual lookups only. | Measure total attributable cost per completed session, including failed starts. Maintain local practice when capacity is unavailable. |
| Skeptical competitor | Langua already combines conversation help and flashcards. Attraction to Parlo's motifs could explain preference. | Match the tasks and counterbalance product order. Require better transfer or less effort at comparable accuracy before claiming advantage. |

The dispute with the greatest product consequence is voice engagement versus learning transfer. Keep the voice entry prominent and build the pilot around what learners can say a week later. The second is room novelty versus object recall. The existing three rooms are sufficient to run that comparison.

## L. Three experiments worth running

1. **Does retrieval transfer?** Recruit consenting A2–B1 learners of one language. Counterbalance six matched expressions per learner between recall and rereading. Match time, model exposure and example count. At day seven a blinded rater scores a new invitation, request or clarification prompt. Report invited and returned denominators with uncertainty. Use the pilot variance and the smallest worthwhile 10-point effect to size the follow-up. If only immediate recognition improves, change the cue and retest.
2. **Does the optional explanation earn its place?** Compare a short meaning with the same meaning plus an optional grammar or register note. Randomize by expression and counterbalance order. Measure appropriate usage in a new exchange, time to resume speaking and cases where a note causes an error. Advance the explanation style if transfer improves without a material increase in abandoned attempts. Interview people from both arms to distinguish confusion from curiosity.
3. **Do rooms help a learner name things later?** Present the same objects, names, voices, examples and time limit as a 3D room or a conventional list. Counterbalance scene and condition across participants. At day seven ask learners to name the objects in unfamiliar photographs. Keep separate denominators for low-end device failures. Expand 3D only if delayed naming improves and phone users can still complete the task.

## M. Next implementation brief

The remaining product question is whether the improved loop helps someone respond in a different conversation. Run one French A2–B1 pilot before adding more content. Use the shipped public invitation page, meaning-first due cards and the existing scheduler. A facilitator can conduct it without new analytics or another paid service.

**Ready-to-use transfer prompt.** On day seven, say privately to the participant, “A colleague invites you to join a group for lunch tomorrow. Accept warmly in French, in your own words.” Do not show the original target or any example first. Accept *Avec plaisir !*, *Oui, ça me ferait plaisir* and other natural expressions that convey the intent. An independent rater scores communicative success and appropriate register separately from reuse of the originally studied expression. Record the first answer, assistance, elapsed time and any disagreement under a consented study ID.

**Decision.** Pilot six counterbalanced expressions, each with an unseen follow-up. Report how many eligible learners returned, how many responded appropriately without help, and how many reused an expression. Use the results to revise cues and size a controlled follow-up. End recruitment or revise the task if raters cannot agree on what counts as a successful reply. The completed implementation supplies the study and review steps.
