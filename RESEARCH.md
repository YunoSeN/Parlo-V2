# Parlo research and review methods

Reviewed 21 November 2026. The last column records the decision the source informed. Dates are given for dated research and editions. Product and documentation links are living pages. Product owners describe their own capabilities. Their pages cannot establish comparative learning effectiveness.

## Learning, language and immersion

| Source | Evidence and application |
|---|---|
| 1. [Council of Europe, CEFR Companion Volume (2020)](https://rm.coe.int/cefr-companion-volume-with-new-descriptors-2020/16809ea0d4) | Use an observable conversational task for A2–B1 and distinguish linguistic, sociolinguistic and pragmatic competence. |
| 2. [Council of Europe, Mediation](https://www.coe.int/en/web/common-european-framework-reference-languages/mediation) | Ask the learner to explain or reformulate a phrase for another listener. |
| 3. [Japan Foundation, What is Irodori?](https://www.irodori.jpf.go.jp/en/about.html) | Practical Can-do tasks offer a model for a first successful exchange. |
| 4. [Karpicke and Roediger, Science (2008)](https://learninglab.psych.purdue.edu/downloads/2008/2008_Karpicke_Roediger_Science.pdf) | Their foreign-language vocabulary experiment supports testing delayed production after retrieval. Parlo still needs its own outcome study. |
| 5. [Nakata, expanding and equal spacing in L2 vocabulary learning (2015)](https://www.cambridge.org/core/journals/studies-in-second-language-acquisition/article/abs/effects-of-expanding-and-equal-spacing-on-second-language-vocabulary-learning/D1D796306985C52F9BE7A1200AC50DB9) | Hold total practice time and number of exposures constant when comparing review schedules. |
| 6. [Nakata and Elgort, Second Language Research (2021)](https://journals.sagepub.com/doi/full/10.1177/0267658320927764) | Effects on explicit and tacit vocabulary knowledge can differ. Include transfer to a new exchange. |
| 7. [Fuhrman and colleagues, The Moving Learner (2021), author abstract via ERIC](https://eric.ed.gov/?id=EJ1294155) | An object-manipulation VR experiment makes a matched object-learning test worthwhile. Parlo's browser diorama is a different intervention. |
| 8. [Unicode, UAX 29](https://unicode.org/reports/tr29/) | Word segmentation can require dictionary or language-specific tailoring. A fixed character count cannot establish a word boundary. |
| 9. [Office québécois de la langue française, modal uses of the conditional](https://vitrinelinguistique.oqlf.gouv.qc.ca/24148/la-grammaire/le-verbe/temps-grammaticaux/conditionnel/valeur-modale-du-conditionnel) | Grounds the French guide's explanation of a possible event. |
| 10. [Larousse, plaisir](https://www.larousse.fr/dictionnaires/francais/plaisir/61343) | Grounds the meaning of the French expression in the guide. |

## GitHub methods actually used

I read the public methods and applied the procedures below directly. GitHub supplied the skill files. Firecrawl's free catalogue lookup returned business research workflows outside the learning task. Source verification used primary pages through web research. The local PDF, product-design audit, test-value, accessibility, Core Web Vitals, SEO and analytics KPI skills informed the companion review. No skill installer or paid research provider was required.

| Public method | Contribution in this project | Limit |
|---|---|---|
| [Matt Pocock, codebase-design](https://github.com/mattpocock/skills/blob/main/skills/engineering/codebase-design/SKILL.md) | Placed segmentation, model-response parsing and pending phrase edits behind small testable interfaces. | A clean interface does not test an actual cloud account. |
| [Matt Pocock, diagnosing-bugs](https://github.com/mattpocock/skills/blob/main/skills/engineering/diagnosing-bugs/SKILL.md) | Exercised the production entry point independently of the Vite build and fixed the failing imports. | Verified on the available Node 24 runtime. |
| [obra, systematic-debugging](https://github.com/obra/superpowers/blob/main/skills/systematic-debugging/SKILL.md) | Followed the wrong-language output through the scenario fallback, prop sheet and save path. | Script and fixture checks cannot decide regional idiomatic quality. |
| [obra, test-driven-development](https://github.com/obra/superpowers/blob/main/skills/test-driven-development/SKILL.md) | Specified the phrase deck, localization, lookup and parsing behaviors before creating the new modules. | First failure was a missing module. Later assertions discriminate the actual behaviors. |
| [obra, verification-before-completion](https://github.com/obra/superpowers/blob/main/skills/verification-before-completion/SKILL.md) | Kept type checks, production boot, unit results and browser evidence independent. | Live billing, speech quality and cohort outcomes have separate gates. |
| [obra, writing-plans](https://github.com/obra/superpowers/blob/main/skills/writing-plans/SKILL.md) | Ordered changes by dependency, starting with source verification and ending with packaged artifact checks. | Effort ranges are estimates. |
| [Vercel, React best practices](https://github.com/vercel-labs/agent-skills/blob/main/skills/react-best-practices/SKILL.md) | Deferred three secondary views and measured the whole initial JavaScript dependency set. | Compressed bytes alone do not establish mobile latency. |
| [Vercel, composition patterns](https://github.com/vercel-labs/agent-skills/blob/main/skills/composition-patterns/SKILL.md) | Kept one active practice card and reused the existing save and speech interfaces. | No broad component rewrite was warranted. |
| [Vercel, web design guidelines](https://github.com/vercel-labs/agent-skills/blob/main/skills/web-design-guidelines/SKILL.md) | Checked keyboard disclosure, focus, stable navigation and visible recovery. | Formal conformance requires wider manual review. |
| [Anthropic, webapp-testing](https://github.com/anthropics/skills/blob/main/skills/webapp-testing/SKILL.md) | Used Playwright to follow the actual UI from first entry to saved and scheduled review. | Desktop Chromium emulation cannot measure native iOS Safari. |
| [Anthropic, PDF](https://github.com/anthropics/skills/blob/main/skills/pdf/SKILL.md) | Extracted all 14 pages of the older assessment and checked its 3D and learner-memory claims against this ZIP. | Its feature scoring is historical judgment. |
| [Vercel, find-skills](https://github.com/vercel-labs/skills/blob/main/skills/find-skills/SKILL.md) | Used task keywords and repository paths to select applicable methods. | Discovery was performed through GitHub. The CLI installer was not run. |
